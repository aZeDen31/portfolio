## Comment fonctionnent les commits

Si vous regardez mes commits, vous remarquerez qu'ils ont tous la même structures, donc voici un guide pour mieux les comprendre.

Dans un commit, chaque changement apporté doit être précédé d'un symbole entourrés de crochets. Voici leurs utilisations : 
- [+] Ajout d'un élément
- [-] Suppression d'un élément
- [~] Modification d'un élément
